# Функционал форумов Discord для бота

Этот модуль добавляет возможность автоматического создания публикаций в форумах Discord при отправке форм.

## Возможности

✅ **Автоматическое создание публикаций** - при отправке формы создается новая публикация в форуме  
✅ **Добавление тегов** - автоматически добавляется тег "In Progress"  
✅ **Гибкая настройка** - можно настроить форум через команды

## Команды

### Список форумов

```
!listforums
```

Показывает все доступные форумы на сервере с их ID и упоминаниями.

### Проверка тегов

```
!checktags
```

Проверяет теги в настроенном форуме и показывает, есть ли тег "In Progress".

### Настройка форума

```
!setupforum <форум>
```

Настраивает форум для автоматических заявок. Форум можно указать:

- По названию: `!setupforum applications`
- По ID: `!setupforum 123456789`
- По упоминанию: `!setupforum #applications`

### Отправка формы в форум

```
!sendforumform [#канал-форума]
```

Отправляет форму в указанный форум или в настроенный форум (если канал не указан). При заполнении формы автоматически создается публикация.

### Обычная отправка формы

```
!sendform [#канал]
```

Отправляет форму в обычный текстовый канал (без создания публикаций).

## Настройка

1. **Создайте форум** в Discord сервере
2. **Создайте тег "In Progress"** в форуме (или другой тег по вашему выбору)
3. **Настройте форум** командой `!setupforum`
4. **Отправьте форму** командой `!sendforumform`

## Пример использования

```
!listforums
!setupforum applications
!sendforumform
```

После этого любой пользователь, заполнивший форму, автоматически:

- Создаст публикацию в форуме #заявки
- Публикация будет помечена тегом "In Progress"

## Требования

- Бот должен иметь права на управление каналами
- Форум должен быть доступен боту
- Тег "In Progress" должен существовать в форуме

## Файлы конфигурации

Настройки сохраняются в файл `config/forum_config.json`:

```json
{
  "forum_channel_id": 123456789,
  "in_progress_tag_name": "In Progress",
  "auto_create_threads": true
}
```
